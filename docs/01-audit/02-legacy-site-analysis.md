# تحليل الموقع القديم `hadramout.center` (Legacy Site Analysis)

> **طريقة الجمع:** سحب مباشر للصفحات (HTTP) في 14 أكتوبر 2026، وعدّ العناصر عبر ترقيم الصفحات حتى الصفحة الفارغة. الأرقام خام في `evidence/legacy-site-counts.json`.

## 1. التقنية

- مبني بـ **Next.js (App Router)** مع بث المحتوى (Streaming/Suspense): محتوى التفاصيل داخل عناصر `<div hidden id="S:n">` ثم يُستبدل بالسكربت.
- الصور على `files.hadramout.center/media/YYYY/MM/...` وتُخدَم عبر `/_next/image`.
- ملفات PDF على `files.hadramout.center` وعلى `s3.me-south-1.amazonaws.com/assets.hadramout.center/uploads/...`.
- الشعار: SVG بألوان `#2A836E` (أخضر مزرق) و`#C49952` (ذهبي) و`#FEEE0B` (أصفر صغير). متغيرات الموقع: `--brand-primary: 165 51% 34%`، `--brand-background: 36 100% 98%`، `--brand-secondary-text: 25 46% 33%`.
- المسار `/about` يعيد صفحة «لم نتمكن من العثور على الصفحة» رغم أن الرابط موجود في الرئيسية → **عيب مؤكد**.
- لا بحث، ولا لغات، ولا استشهاد علمي، ولا ترتيب حسب المؤلف.

## 5. مخاطر خاصة بالاستيراد

| الخطر | المعالجة |
|---|---|
| حجم الصور (بعضها 2.5MB+) | تنزيل + توليد 3 أحجام WebP، والإبقاء على الأصل الاحتياطي |
| تنسيق HTML متفاوت (محتوى WordPress) | تعقيم صارم بقائمة بيضاء + تنظيف `&nbsp;` والوسوم الفارغة |
| تواريخ نصية عربية | محلل تواريخ عربي («أكتوبر» ... «سبتمبر») إلى ISO |
| معدّل الطلبات | مهلة بين الطلبات + User-Agent واضح + إمكانية الاستئناف |
| حقوق المحتوى | المحتوى ملك المركز وهو عميل المشروع؛ يُؤكَّد في وثيقة التسليم |
