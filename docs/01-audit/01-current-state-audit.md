# تقرير تدقيق الوضع الحالي للمشروع (Current State Audit)

> **تاريخ التدقيق:** 14 أكتوبر 2026 · **النطاق:** كامل المستودع (الفروع، الكود، البيانات، الوثائق، سير العمل CI/CD) + مقارنة مع الموقع الحي `hadramout.center`
> **المنهج:** كل بند أدناه **مقاسٌ أو مُتحقَّقٌ منه فعلياً** (أوامر قياس، سحب الموقع القديم، قراءة الكود). ما لم نتحقق منه نذكره صراحةً كـ«غير مُتحقَّق».

## 1. الملخص التنفيذي

| السؤال | الجواب |
|---|---|
| كم فرعاً في المستودع؟ | فرع واحد فعلي: `master` (= `origin/master`، آخر commit `8435b56`). الفرع `claude/project-review-refactor-*` هو فرع العمل الحالي ويطابق `master`. **لا توجد فروع أخرى للمراجعة أو الدمج.** |
| هل المشروع جاهز للإنتاج؟ | **لا.** رغم أن الوثائق تقول «Production Ready 100%»، فإن سكربت الفحص يتحقق من **وجود الملفات والحقول فقط** ولا يختبر روابط ولا وصولية ولا أداء ولا متصفح. |
| هل يغطي محتوى الموقع القديم؟ | **لا — أقل من 2%.** الموقع الحي فيه **1,461 عنصراً**؛ المشروع الحالي فيه 4 أخبار من 391 و13 مقالاً من 912. |
| هل البيانات صحيحة؟ | **جزء منها مختلَق** (مخطوطات برقم حفظ وهمي، حلقة بودكاست بملف صوت غير موجود، مؤشر «5000+ وثيقة»). هذا يخالف قاعدة المشروع نفسه «عدم التلفيق» ويُعرّض سمعة مركز بحثي للخطر. |
| هل يلبي طلب العميل؟ | **لا.** العميل يريد إدخال المحتوى بالعربية فقط وترجمة تلقائية لكل اللغات. المشروع الحالي: لا لوحة إدارة (تعديل ملف JS يدوياً)، والترجمة عبر أداة Google Translate الجاهزة (غير قابلة للأرشفة). |
| القرار | **إعادة بناء من الأساس** بمعمارية قائمة على قاعدة بيانات + عرض من الخادم (SSR) + لوحة إدارة + ترجمة آلية حقيقية، مع الاحتفاظ بما هو سليم من الأفكار (RTL، استشهادات علمية، PWA). |

## 4. ما يستحق البقاء من العمل السابق

| العنصر | القرار |
|---|---|
| فكرة مولد الاستشهادات (APA/Chicago/MLA/BibTeX/RIS) | ✅ يُعاد بناؤها بشكل أدق + وسوم Google Scholar |
| اتجاه RTL أولاً وثنائية اللغة | ✅ يُوسَّع إلى أي لغة |
| PWA وقراءة دون اتصال | ✅ يُعاد بناؤها على بنية جديدة |
| بيانات الاتصال الرسمية والحسابات الاجتماعية | ✅ مُتحقَّق منها من الموقع الحي |
| 52 كتاباً (تطابق مع الموقع الحي) | ✅ تُستبدل بالاستيراد الآلي المباشر لضمان الدقة |
| الخط الزمني التاريخي | ⚠️ يُعاد بمحتوى مرجعي موثّق ويُوسَم «بحاجة مراجعة علمية» |
| مخطوطات/بودكاست/«5000+ وثيقة» | ❌ تُحذف نهائياً |
| لوحة الأوامر، أصوات Haptics، معاين OG | ❌ تُحذف (بحث موحد أفضل وبطاقات OG حقيقية) |
