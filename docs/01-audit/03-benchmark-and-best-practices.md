# المقارنة المرجعية وأفضل الممارسات (Benchmark & Best Practices)

> الهدف: أن تكون كل قرارات التصميم والهندسة مبنية على مصادر رسمية لا على الانطباع. المراجع بعد كل بند.

## 1. السيو متعدد اللغات والمحتوى المترجم آلياً

| الموضوع | الخلاصة | القرار في المشروع |
|---|---|---|
| بنية الروابط | توصي جوجل بخيارات: نطاق وطني، نطاق فرعي، **مجلد فرعي (`/de/`)**، أو بارامتر. البارامتر **غير موصى به**. المجلد الفرعي سهل الإعداد وقليل الصيانة على مضيف واحد | `/{lang}/...` (مثل `/en/articles/9597`) |
| `hreflang` | يجب أن يكون متبادلاً (كل صفحة تشير لكل نسخها وإلى نفسها) مع `x-default` | يُولَّد تلقائياً لكل صفحة ولكل خريطة موقع |
| المحتوى المترجم بالذكاء الاصطناعي | حدّثت جوجل وثائقها (يونيو 2025): **الترجمة الآلية ليست سبّاماً بحد ذاتها، والحكم لجودتها وفائدتها** لا لأسلوبها | نسمح بفهرسة اللغات التي اكتملت ترجمتها فقط، ونضع `noindex` للترجمات الجزئية/المختلطة |
| الشفافية | ينبغي إعلام القارئ بأن النص مترجم آلياً | شارة «ترجمة آلية — النص العربي هو المرجع» + رابط للأصل |

المراجع: [Managing multi-regional and multilingual sites](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites) · [Localized versions of your pages](https://developers.google.com/search/docs/specialty/international/localized-versions) · [Google Relaxes Policy on AI-Translated Web Content (MultiLingual, 2025)](https://multilingual.com/google-automated-translation-policy-update/)

## 2. الفهرسة الأكاديمية (Google Scholar)

الشروط المنشورة للمواقع الأكاديمية:
- وسوم إلزامية: `citation_title` و`citation_author` (وسم لكل مؤلف، بلا ألقاب/انتماءات) و`citation_publication_date`.
- عنوان الورقة في `<h1>`/`<h2>` وهو أكبر نص في الصفحة، والمؤلفون قبله أو بعده مباشرة.
- التلخيص (abstract) متاح مجاناً، ومسار الـPDF (`citation_pdf_url`) في نفس المجلد الفرعي.
- يُنصح بـ`citation_journal_title` و`citation_volume`/`citation_issue` للمقالات المنشورة في المجلة.

**القرار:** كل مقال وكتاب وعدد يخرج بوسوم `citation_*` + JSON-LD (`ScholarlyArticle`، `Book`، `PublicationIssue`، `Event`) + بيانات COinS لمدير المراجع Zotero. المصدر: [Inclusion Guidelines for Webmasters — Google Scholar](https://scholar.google.com/intl/en/scholar/inclusion.html).

## 4. المقارنة مع مواقع مرجعية (ما نتعلمه)

| المرجع | ما يفعله جيداً | ما نأخذه |
|---|---|---|
| دارة الملك عبدالعزيز (السعودية) | هوية تراثية رصينة، بحث بالتصفية حسب العصر والمنطقة، واجهة ثنائية اللغة | تصفية بالعصر/التصنيف/المؤلف/السنة |
| مؤسسة العويس الثقافية (الإمارات) | تسلسل طباعي عربي ممتاز، صفحة مستقلة لكل إصدار وفهرسه | صفحة عدد مجلة بفهرس مقالات وروابط مباشرة |
| Brill / Leiden Digital Collections | استشهادات معيارية، ملخصات، فهرسة | وسوم Scholar + تصدير RIS/BibTeX/CSL-JSON |
| مكتبة قطر الرقمية | قارئ وثائق، ثنائية اللغة، بيانات وصفية غنية | قارئ مريح + بيانات وصفية |
| الموقع القديم للمركز | محتوى ضخم وموثق (1,461 عنصراً) | **كل محتواه يُنقل**؛ نضيف ما ينقصه: بحث، لغات، استشهاد، فرز |

## 5. الأداء على شبكات ضعيفة (واقع اليمن)

- ميزانية الأداء: HTML الرئيسية ≤ 40KB مضغوطاً، CSS ≤ 25KB، JS الحرج ≤ 30KB، خط واحد حرج ≤ 70KB، صور الغلاف ≤ 40KB (WebP).
- أهداف Core Web Vitals على هاتف متوسط وشبكة 4G بطيئة: LCP ≤ 2.5s، INP ≤ 200ms، CLS ≤ 0.1.
- تحميل الصور كسولاً، `fetchpriority="high"` لصورة LCP، ذاكرة مؤقتة قوية للأصول بتجزئة المحتوى، ضغط Brotli.

## 6. الوصولية

- WCAG 2.2 AA: تباين ≥ 4.5:1 للنص، 3:1 للمكونات، حجم هدف اللمس ≥ 44px، إدارة التركيز، `prefers-reduced-motion`، `prefers-color-scheme`، روابط تخطي، تسميات ARIA، `lang` على كل مقطع بلغة مختلفة.
- RTL أولاً باستخدام الخصائص المنطقية (`margin-inline`, `inset-inline-start`) بدل `left/right`.

## 7. الأمان لتطبيق خادم صغير

- OWASP ASVS (المستوى 1–2): تعقيم المخرجات تلقائياً، CSRF، جلسات بكوكي `HttpOnly; Secure; SameSite=Lax`، تجزئة كلمات المرور بـscrypt، تحديد معدل الطلبات، رفع ملفات محكوم (نوع/حجم/إعادة ترميز)، سجل تدقيق.
- رؤوس: CSP صارم، HSTS، `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`, `Cross-Origin-Opener-Policy`.
- أسرار البيئة خارج المستودع، وفحص الاعتماديات (`npm audit`) في CI.

| المزوّد | الجودة للعربية⟷X | التكلفة | ملاحظات |
