## قواعد التعامل مع محتوى العميل
- **لا اختلاق:** كل نص مؤسسي على الموقع مأخوذ من كتاب المركز نفسه ويُذكر مصدره (رقم الصفحة) في الكود والوثائق. ما لا يوجد في الملفين يُترك ولا يُخمَّن.
- **القراءة:** طبقة نص الـPDF تُستخرج لكنها تُسقط حروفًا مركبة (مثل «حضرموت» ← «حموت»)، فنُقلت الجداول مع مطابقتها بصور الصفحات. **الأرقام والتواريخ والأسماء تحتاج تأكيد المركز** قبل الإطلاق (البند CF-24).
- **الصور والشعارات:** لا تُنسخ صور الكتاب إلى الموقع قبل إذن المركز؛ وأي شريك لا يظهر شعاره قبل موافقته الكتابية (حقل `hasWrittenConsent`).
