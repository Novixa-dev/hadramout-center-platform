القائمة «تتسع تلقائياً»: ما لا يتسع في عرض الشاشة يدخل «المزيد». على الجوال تُعرض كمقاطع مرتبة في درج جانبي. للمحرر أن يضيف صفحة إلى الشريط أو «المزيد» من حقل موضع الرابط في الصفحة.

أبرز ميزات الزائر

البحث والتصفح

  • بحث نصي عربي ذكي (تطبيع الحروف والسوابق) مع اقتراحات فورية وسجل بحث.
  • فلاتر لكل قسم: الموضوع (شجرة)، الكاتب، السنة، الترتيب، وعرض شبكي/قائمة.
  • صفحات للكتّاب (272) وللمواضيع، وخط زمني تاريخي.

القراءة

  • مقالات بقياس قراءة مريح، فهرس محتويات، شريط تقدّم، وإعدادات الخط والعرض.
  • نسخ مع إسناد تلقائي للمصدر، وطباعة نظيفة.
  • استشهاد جاهز: APA وMLA وChicago وHarvard، وتصدير RIS وBibTeX وCSL-JSON.

حسابك دون تسجيل

  • «محفوظاتي»: حفظ المقالات في المتصفح (لا تُرسل لأي خادم).
  • قراءة المحفوظات دون اتصال (Service Worker محافظ).
  • تقييمات وآراء القرّاء بعد مراجعة المحرر.

البيانات المفتوحة

  • تصدير فهرس الكتب والمجلات CSV/JSON.
  • خلاصات RSS لكل لغة ولكل موضوع ولكل كاتب.
  • ملف iCal لكل فعالية، ورابط «أضف إلى تقويم جوجل».

الصفحات

منشئ صفحات بـ11 نوع كتلة، معاينة حية، حقول SEO وصورة المشاركة، وتحديد موضع الصفحة في القوائم (الرئيسية/المزيد/الفوتر).

الذكاء والكتابة

مساعد تدقيق عربي علمي (علامات الترقيم، الاقتباس العربي)، وتعبئة تحريرية بالذكاء الاصطناعي (ملخص، كلمات مفتاحية) عند ضبط مفتاح المزوّد.

الترجمة

قاموس المصطلحات، بلاغات أخطاء الترجمة، وحد استهلاك يومي يظهر في اللوحة.

الصفحة الرئيسية للوحة

  • ما يحتاج انتباهك: مراجعات معلّقة، رسائل جديدة، مقالات بلا تصنيف، مسودات، آخر فعالية — كل رقم رابط إلى قائمة مصفّاة.
  • حالة المحتوى: منشور/مسودة/مؤرشف لكل قسم، وزر «إضافة».
  • آخر التعديلات والترجمة اليوم واختصارات.
تقرير جودة التحرير الأمر npm run quality يطبع قائمة عمل للمحررين: مقالات بلا تصنيف، كتب بلا ISBN، صور بلا نص بديل، كتّاب بأسماء غير صالحة، بحث بلا نتائج. لا يغيّر شيئاً ولا يخمّن.

٤ دليل المحرر خطوة بخطوة

القاعدة الذهبية أدخل المحتوى بالعربية فقط. النظام يترجمه لأي لغة يطلبها الزائر. لا تُدخل لغة أخرى يدوياً إلا لتصحيح ترجمة.

نشر خبر أو مقالة

  1. ادخل /admin ← القسم (الأخبار أو المقالات) ← «إنشاء جديد».
  2. املأ: العنوان · الملخص · النص · الصورة · التاريخ · الكاتب · التصنيف (للمقالات).
  3. اضبط الحالة: «مسودة» لا تظهر للزوار، «منشور» تظهر فوراً. الموصى به: المحرر يحفظ مسودة والمدير ينشر.
  4. احفظ. تظهر في الموقع والبحث والخلاصات والخريطة تلقائياً.

إضافة مؤتمر أو ندوة أو محاضرة

  1. القسم «المؤتمرات والندوات» (أو «منتدى عميد الوفاء») ← إنشاء.
  2. الحقول: العنوان · تاريخ البداية والنهاية · المكان · المتحدث · مدير الجلسة · الجهات الداعمة · طريقة الحضور (حضوري/افتراضي/كلاهما) · رابط الحضور · فيديو يوتيوب.
  3. المحاور ورؤساء الجلسات والأوراق البحثية (عنوان، باحث، ملخص، ملف PDF).
  4. تظهر في الصفحة أزرار «أضف إلى التقويم» (ملف iCal) و«أضف إلى تقويم جوجل» تلقائياً.

إضافة كتاب أو عدد

الكتب: الغلاف · المؤلفون · الناشر · الطبعة · ISBN · عدد الصفحات · رابط PDF. الأعداد: رقم العدد (فريد) · الغلاف · PDF · المحتويات. لا تُخمّن ISBN أو عدد الصفحات؛ اتركها فارغة إن لم تعرفها.

إنشاء صفحة جديدة

  1. «الصفحات» ← جديد ← العنوان والعنوان المختصر (slug) ← المحتوى بالكتل.
  2. تبويب موضع التنقل: اختر «القائمة الرئيسية» أو «المزيد» أو أعمدة الفوتر.
  3. تبويب SEO: عنوان ووصف وصورة المشاركة، و«عدم الفهرسة» عند الحاجة.

الإعلان العاجل

القسم «الإعلانات»: نص وصورة وتاريخ بدء وانتهاء. يظهر شريطاً أعلى الموقع ويختفي تلقائياً بعد الانتهاء.

الشركاء و«قالوا عنا»

لا يظهر شعار شريك قبل تحديد موافقة كتابية (hasWrittenConsent)، ولا يُنشر رأي دون إذن صاحبه.

٥ اللغات والترجمة الآلية

زائر يختار لغة←يُترجم النص عند أول طلب←يُحفظ في قاعدة البيانات←يظهر فوراً لكل من يليه
  • الأصل العربي دائماً. لا تُعتمد لغة المتصفح؛ العربية هي الافتراضية، والصفحات المترجمة موسومة بأنها ترجمة آلية.
  • الفهرسة: العربية والإنجليزية فقط (INDEXABLE_LANGS=ar,en) لتفادي محتوى مترجم رديء في نتائج البحث.
  • المزوّدات: none (لا ترجمة) · mock (تطوير) · anthropic · google · libretranslate · cloudflare (Workers AI، مجاني).
  • الضوابط: حد يومي (TRANSLATION_DAILY_CHAR_LIMIT، افتراضي 2,000,000 حرف)، تزامن 2، لغة إنجليزية «متحمّسة» مسبقة.
  • الجودة: قاموس مصطلحات يضمن ثبات أسماء الأعلام والمصطلحات، وتعديل المراجع اليدوي محمي من الاستبدال.
  • الاتجاه: RTL/LTR تلقائياً حسب اللغة، والمقاطع العربية داخل صفحات أخرى موسومة lang="ar".

npm run db:seed -- --defaults-only   # الصفحات والإعدادات فقط

٨ محركات البحث ومشاركة الروابط

  • الإطلاق مقفل بمفتاح واحد: SITE_ENV=production هو الوحيد الذي يجعل الموقع قابلاً للفهرسة؛ غيابه = noindex + شريط معاينة + robots.txt بلا خريطة.
  • عنوان ووصف ورابط قانوني (canonical) وبدائل اللغات (hreflang مع x-default) لكل صفحة.
  • بيانات منظمة JSON-LD: Organization · WebSite (مع SearchAction) · Article · Book · Event (فقط عند وجود تاريخ) · VideoObject · ProfilePage · BreadcrumbList.
  • بطاقات المشاركة OG: 1200×630 تُرسَم عند الطلب بعنوان الصفحة؛ للمقالات المصوَّرة تُستعمل صورة المقال؛ للكتب غلاف الكتاب.
  • sitemap.xml بلا priority/changefreq (يتجاهلهما جوجل) مع lastmod صحيح، وإشعار IndexNow عند الإنتاج.

أوامر يومية

npm ci && cp .env.example .env && npm run payload migrate && npm run db:seed && npm run dev
npm run check      # typecheck + lint + اختبارات الوحدة
npm run knip       # ملفات وحزم وتصديرات غير مستخدمة
npm run build && npm run smoke    # بناء الإنتاج + فحص التشغيل (RUN_E2E=1 لمتصفح حقيقي)
npm run quality    # تقرير جودة المحتوى
فخاخ موثّقة: البناء المحلي يتطلب TRANSLATION_PROVIDER=none · لا تجعل سكربتات prepare/postinstall تعتمد على ملفات المستودع (تُنفَّذ داخل Docker) · لا تلتقط كل الأخطاء كـ «غير موجود»: 404/403 فقط.

١١ التشغيل: GitHub والنشر التلقائي والنسخ الاحتياطي

مسار العمل

تعديل محلي←npm run check + بناء + smoke←commit (hook يفحص)←fast-forward إلى master←CI + Deploy تلقائياً←فحص الموقع الحي

قاعدة المالك: لا طلبات دمج لعمل الفريق؛ تُدفع الدفعات المختبرة مباشرة (fast-forward، لا force). تحديثات Dependabot تُدمج عبر GitHub بعد نجاح فحوصاتها.

التراجع والنسخ الاحتياطي

  • النسخة الاحتياطية قبل كل نشر (backup.sh pre-deploy) تشمل قاعدتي البيانات وlegacy-media؛ فشلها يوقف النشر قبل لمس الموقع.
  • يُحتفظ بآخر 3 صور للتراجع. تراجع يدوي: Deploy ← Run workflow ← tag=sha-xxxxxxx.
  • يومياً بـcron: 15 3 * * * backup.sh daily. الاستعادة: scripts/restore.sh. نسخة خارج الخادم لم تُضبط بعد (قرار المالك).

الإطلاق والانتقال إلى نطاق جديد

  1. اعتماد المركز (البند CF-24 في خطة العميل) ثم تحديد المضيف والنطاق.
  2. اتبع docs/05-deploy/03-move-to-new-host-and-domain.md (قوالب Caddy جاهزة).
  3. اضبط SITE_URL وSITE_ENV=production وأعد إنشاء الحاوية: docker compose up -d --force-recreate app.
  4. تحقق: node scripts/cutover-check.mjs https://النطاق (المضيف، الفهرسة، الخريطة، التحويلات، الرؤوس).

١٥ خارطة الطريق والأفكار

قبل الإطلاق (بوابات)

  1. اجتماع العميل وتسليم المواد (CF-04…CF-18) واعتماد الأرقام (CF-24).
  2. قرارات المالك: نطاق واستضافة، مزوّد ترجمة، Cloudflare، التحقق بخطوتين، نسخ خارج الخادم، مزوّد بريد.
  3. مراجعة يدوية بقارئ شاشة ولوحة مفاتيح، وبروفة استعادة النسخ الاحتياطي على المضيف الجديد.

بعد الإطلاق

  • Search Console وقياس Core Web Vitals الميدانية، وتقرير الجودة أسبوعياً.
  • مرحلة 2: العضويات، المتجر، الموسوعة الحضرمية، التبرعات والتطوع، منصة حضرموت الثقافية.
  • نشر بلا انقطاع (حاويتان وتبديل)، ودمج تلقائي لتحديثات Dependabot البسيطة.
  • نصوص بديلة للصور (4,004 صورة) بمساعدة اقتراح آلي يراجعه محرر.
  • رابط «أضف إلى تقويم جوجل» للإعلانات، وصفحة أرشيف للإعلانات، ونوع «محاضرة/ندوة/مؤتمر» كحقل مستقل مع فلتر.
