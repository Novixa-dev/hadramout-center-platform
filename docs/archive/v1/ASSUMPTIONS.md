# Explicit Project Assumptions & Boundary Constraints

1. **Content Authenticity:** All indexed publications, journal numbers, author names, and physical office addresses are derived directly from verified primary sources issued by the Center. No claims or individuals have been fabricated.
2. **Infrastructure:** The Hadhramout Center owns the `hadramout.center` domain name and has DNS administrative access to point records to the new edge CDN.
3. **Operational Model:** The Center prefers an ultra-fast, zero-overhead static platform over a complex database-backed CMS requiring regular server maintenance, security patches, and database backups.
4. **Bilingual Reach:** While Arabic is the definitive institutional language, English metadata is required to facilitate indexing by international academic search engines and diaspora scholars.
5. **E-Commerce Reality:** Due to international financial sanctions and local banking restrictions in Yemen, physical book acquisitions are handled via direct staff communication (WhatsApp/Phone/Email) rather than automated credit card transactions.
