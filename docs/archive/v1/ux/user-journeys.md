# End-to-End User Journeys

**Initiative:** Novixa UX Design  
**Platform:** Hadhramout Center Digital Platform  

---

## Journey 1: Academic Research & Citation Discovery
```
[User arrives on Homepage]
       │
       ▼
[Clicks "البحث الأكاديمي" in Header or uses Search Hero Bar]
       │
       ▼
[Types query: "الصلات العلمية بين حضرموت وظفار"]
       │
       ▼
[Instant results filter down: Category = العلاقات الإقليمية]
       │
       ▼
[Selects Book: "العلاقات السياسية والصلات العلمية بين حضرموت وظفار"]
       │
       ▼
[Views details modal / page with synopsis, author, publishing year]
       │
       ▼
[Clicks "نسخ الاقتباس (APA)" -> Toast confirms "تم نسخ التوثيق بنجاح!"]
       │
       ▼
[Clicks "تحميل المستخلص / الفهرس (PDF)"]
```
