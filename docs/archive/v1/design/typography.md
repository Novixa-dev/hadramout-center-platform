# Typography System & Font Pairing Guidelines

**Platform:** Hadhramout Center Digital Platform  
**Design Studio:** Novixa  

---

## 1. Primary Typefaces

### 1.1 Arabic Primary: `IBM Plex Sans Arabic`
- **Weights:** Light (300), Regular (400), Medium (500), SemiBold (600), Bold (700)
- **Rationale:** Exceptionally legible modern geometric sans-serif tailored for Arabic digital typography. Features balanced proportions, clear baseline alignment, and outstanding readability across mobile and retina displays.

### 1.2 English Primary: `IBM Plex Sans` & `Inter`
- **Weights:** Regular (400), Medium (500), SemiBold (600), Bold (700)
- **Rationale:** Harmonizes seamlessly with the Arabic counterpart, delivering unified rhythmic spacing in bilingual environments.

### 1.3 Classical / Literary Fallback: `Amiri`
- **Usage:** Academic citations, epigraphic quotes, and historical manuscript captions.
- **Rationale:** Traditional Naskh typeface designed for scholarly, classical Arabic prose.

---

## 2. Typographic Scale & Modular Ratio
- **Hero Title (`h1`):** `clamp(2.2rem, 5vw, 3.4rem)` / Line height: 1.25 / Bold 800
- **Section Heading (`h2`):** `clamp(1.75rem, 3.5vw, 2.35rem)` / Line height: 1.35 / Bold 700
- **Card Heading (`h3`):** `1.15rem` – `1.25rem` / Line height: 1.45 / SemiBold 600
- **Body Text (`p`):** `1rem` (16px) / Line height: 1.7 / Regular 400
- **Eyebrow Badges:** `0.8rem` / Line height: 1.2 / Bold 700 / All Caps in English
