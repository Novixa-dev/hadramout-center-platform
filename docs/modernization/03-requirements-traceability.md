# 03. مصفوفة تتبع المتطلبات والمطابقة المؤسسية
## Requirements Traceability Matrix: Source Documents, Center Feedback & Platform Parity

> **المصادر المرجعية:** كتاب إنجاز المركز، تقرير ملاحظات المركز ومقترحات الموقع، متطلبات الشريك التقني (نوفكسا)، والكود المصدري الفعلي.  
> **حالات المتطلب:**  
> - `EXISTS`: موجود ومكتمل برمجياً في المنصة.  
> - `PARTIAL`: موجود جزئياً ويتطلب تحسيناً أو استكمال حقول.  
> - `MISSING`: غير موجود حالياً ومقترح للتطوير.  
> - `DUPLICATE`: مكرر ودمجه أفضل معمارياً.  
> - `BLOCKED`: متوقف على قرار تقني أو مزود خدمة خارجي.  
> - `NEEDS CENTER APPROVAL`: يتطلب اعتماداً صريحاً أو تزويد مواد من إدارة المركز.

## 4. متطلبات الحقول التحريرية التفصيلية المقترحة للمجموعات

| المجموعة | الحقول الحالية في الكود | الحقول الجديدة المقترحة والمطلوبة من التقرير | التوافق المعماري |
|---|---|---|---|
| **المؤتمرات والندوات (`events`)** | `title`, `speaker`, `moderator`, `venue`, `timeText`, `eventDate`, `endDate`, `youtubeId`, `link`, `status` | نوع الفعالية (مؤتمر/ندوة)، المحاور البحثية (Themes)، المشاركون والباحثون، عناوين الأوراق البحثية، الجهات الداعمة/الشريكة، وملف جدول الأعمال (PDF). | متوافق، يتطلب ترحيل قاعدة بيانات خفيف وإضافة كتل علاقات. |
| **المحاضرات واللقاءات (`events`)** | نفس حقول الفعاليات أعلاه. | نمط الحضور (حضوري/عن بُعد/هجين)، رابط المنصة الافتراضية، ومسجل اللقاء. | يتم استيعابها بنفس نموذج الفعاليات عبر حقل تصنيف النمط (`mode`). |
| **منتدى عميد الوفاء (`forum-events`)** | نفس حقول الفعاليات، مع وجود معرّف يوتيوب. | تعدد الضيوف والمتحدثين، نبذة عن المنتدى، وألبوم صور الفعالية. | تحويل حقل المتحدث إلى علاقة متعددة أو مصفوفة نصوص. |
| **بودكاست سقاية (جديد)** | غير موجود. | عنوان الحلقة، رقم الحلقة، الموسم، الغلاف، ملف الصوت، روابط المنصات (Spotify, Apple, YouTube)، أسماء الضيوف، والملخص. | مجموعة جديدة أو نموذج فرعي مرتبط بمكتبة السمعيات. |
| **المكتبة السمعية (`audio` - جديد)** | غير موجود. | العنوان، التاريخ، الوصف، المتحدثون، الملف الصوتي المحلي (MP3)، الرابط الخارجي الموثوق، والمدة. | إنشاء مجموعة جديدة `Audio` مع حماية الرفع وتحديد الامتدادات الصوتية. |
| **المكتبة المرئية (`videos`)** | `youtubeId`, `embedUrl`, `guest`, `duration`, `title`, `body` | دعم منصات مرئية بديلة موثوقة، التصنيف الموضوعي، والربط بالفعاليات. | تحديث مجموعة `Videos` القائمة دون ككسر للمادتين الحالية. |
| **الإعلانات (`announcements` - جديد)** | غير موجود. | نوع الإعلان، العنوان، الغلاف، تاريخ البدء والانتهاء، التثبيت في الرئيسية، وزر تنزيل موعد للتقويم (`.ics`). | إنشاء مجموعة `Announcements` مع منطق إخفاء تلقائي بعد تاريخ الانتهاء. |
| **شركاء النجاح (`partners` - جديد)** | غير موجود. | اسم الجهة، الشعار (صورة بصيغة آمنة)، التصنيف (أكاديمي/داعم/حكومي)، رابط الموقع، وموافقة المركز الخطية على النشر. | إنشاء مجموعة `Partners`. |
| **قالوا عنا (`testimonials` - جديد)** | غير موجود. | صاحب الشهادة/الجهة، المقتطف النصي، التاريخ والسياق، وموافقة النشر. | إنشاء مجموعة `Testimonials`. |
| **الصفحات (`pages`)** | `title`, `slug`, `body`, `status` | منشئ كتل (Hero, Text, Grid, Media, FAQ, CTA, etc.)، حقول SEO مفصلة، وموضع التنقل والقوائم. | ترقية شاملة لمجموعة `Pages` وهو جوهر المرحلة 2. |

## 5. الخلاصة الهندسية لمصفوفة التتبع

- نسبة المتطلبات المتوفرة والمحققة كلياً أو جزئياً تتجاوز **65%** من البنية التحتية والمحتوى الأساسي.
- الفجوات الحقيقية تنحصر في:
  1. كماليات لوحة التحكم لتسهيل عمل المحرر غير التقني (Page Builder & Live Preview).
  2. اعتماد نصوص اللجان والهيكل التنظيمي والسياسات مع إدارة المركز.
  3. استكمال استضافة الملفات محلياً وإضافة المجموعات التحريرية الجديدة (السمعيات، الإعلانات، الشركاء).
- لا يوجد أي عائق فني يمنع تنفيذ خطة التحديث بعد الحصول على الموافقة الصريحة للمرحلة B.
