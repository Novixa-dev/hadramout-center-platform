# 13. سجل المخاطر الفنية والتشغيلية والمؤسسية
## Project Risk Register: Identification, Assessment, Mitigation & Ownership

> **الهدف الهندسي:** تحديد المخاطر المحتملة التي قد تهدد استقرار المشروع، أو أمنه، أو سلامة بياناته الأكاديمية، أو جدول إطلاقه الزمني، ووضع خطط تخفيف استباقية واضحة ومسؤوليات محددة.

## 2. بروتوكول تصعيد المخاطر (Escalation Protocol)

1. **المخاطر الحرجة (Level 1 — P0):**
   - تُرفع فوراً وبشكل مكتوب إلى المالك والمهندس الرئيسي (Tech Lead).
   - توقف أي عملية نشر أو دمج حتى اكتمال التخفيف واعتماد خطة العمل البديلة.
2. **المخاطر التشغيلية والبيانية (Level 2 — P1):**
   - تُناقش في اجتماع المراجعة الأسبوعي مع ممثل المركز لاتخاذ قرار إداري أو توفير المواد الناقصة.
   - يتم تتبعها كمهام في [`IMPLEMENTATION_TRACKER.md`](./IMPLEMENTATION_TRACKER.md).
3. **الملاحظات الفنية الطفيفة (Level 3 — P2/P3):**
   - تُعالج مباشرة ضمن دورة التطوير الاعتيادية للمرحلة المعنية.
