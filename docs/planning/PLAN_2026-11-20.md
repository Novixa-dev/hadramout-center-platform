## Decisions taken in this pass

- **"Ads" means the Center's own promotions, not an ad network.** Third-party ads (AdSense and the like) would load foreign scripts and trackers into a scholarly archive, need CSP holes and consent banners, and earn very little at this traffic. The system promotes the Center's own work: events, new releases, calls for papers, donation campaigns, support projects, store offers, volunteering, partners. A partner's sponsored message is possible as a promotion of type «شريك» with a visible label.
- **Timing is exact even on cached pages.** Pages are cached up to 5 minutes (ISR). The server sends promotions that start within the next 24 hours; a small script in `<head>` decides before the first paint which ones are live for this visitor, page and device, so a start or end time is honoured to the minute and nothing shifts the layout.
- **No popup on arrival.** Google demotes pages that cover content as soon as a visitor lands from search, and it is bad manners. Popups wait (default 8 s, or after 40 % scroll), are bottom sheets on phones, and show once per visitor unless the editor chooses otherwise.
- **Counts without tracking people.** Views, clicks and closes are daily totals per promotion in the `extras` database; no cookie, no IP, no visitor id. Browsers that send Do-Not-Track or Global Privacy Control send nothing.
- **Who can manage promotions:** editors and admins create and publish; reviewers can only fix translations; only admins delete (same rules as the rest of the content). A separate «marketing» role is not added: the access rules treat every signed-in user as staff, and a new role would need a full access review first (BACKLOG CF-ROLE-MARKETING).
