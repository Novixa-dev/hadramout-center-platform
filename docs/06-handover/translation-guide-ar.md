# دليل الترجمة الآلية (المجانية)

## كيف تعمل
1. المحرر يكتب بالعربية فقط.
2. عندما يختار زائر لغة غير العربية تُترجم الصفحة **عند أول طلب** وتُحفظ للأبد؛ الطلبات التالية فورية.
3. اللغة الإنجليزية تُترجم تلقائياً عند نشر أي محتوى جديد (`TRANSLATION_EAGER_LANGS=en`).
4. الواجهة (القوائم والأزرار) تُترجم لكل لغة مرة واحدة أيضاً.
5. تعديلك اليدوي على أي ترجمة **محميّ** ولا تُعيد الآلة كتابته.

## المزوّد المعتمد: Cloudflare Workers AI (مجاني)
- نموذج Mistral Small 3.1 24B؛ الحد المجاني **10,000 وحدة (neurons) يومياً** بلا بطاقة دفع.
- يعادل تقريباً **200 ألف حرف عربي يومياً** (≈20 مقالة متوسطة). الحد مضبوط في `TRANSLATION_DAILY_CHAR_LIMIT=200000`.
- عند بلوغ الحد يتوقف الترجمة حتى اليوم التالي (00:00 بتوقيت UTC) ثم تُستأنف تلقائياً؛ الصفحات تبقى بالعربية مع شريط «جارٍ إعداد الترجمة».
- الجودة: جيدة للفهم والقراءة، وليست بديلاً عن مترجم بشري في النصوص الأكاديمية الدقيقة. المقالات المحورية تُراجَع يدوياً من لوحة الإدارة (بدّل اللغة وعدّل).

## الحالة
**مفعّلة على الإنتاج منذ 2026-10-15** (اختُبرت: ترجمة خبر إلى الإنجليزية في ثوانٍ، وإلى الفرنسية مع واجهة الموقع في ≈80 ثانية). نموذج Gemma غير متاح لهذا الحساب، فاعتُمد Mistral Small 3.1 24B بعد مقارنة مع m2m100 (يُسقط اسم المركز) وLlama.

## التفعيل (مرة واحدة)
1. Cloudflare ← My Profile ← API Tokens ← Create Token ← قالب **Workers AI** ← إنشاء، ثم انسخ الرمز.
2. على جهازك شغّل (يطلب الرمز بإخفاء، ويختبره قبل التفعيل):
```bash
ssh -t root@161.97.75.64 /opt/hadramout-center/scripts/enable-translation.sh
```
3. افتح أي صفحة بلغة غير العربية وانتظر ثوانٍ.

## بدائل إن احتجت جودة أعلى لاحقاً
`TRANSLATION_PROVIDER=anthropic` (يتطلب مفتاحاً مدفوعاً) أو `google`/`libretranslate` — راجع `docs/02-plan/04-i18n-and-translation.md`.
