# وثيقة التسليم — منصة مركز حضرموت

**التاريخ:** 2026-11-06 · **الجمهور:** مدير المركز، فريق التحرير، مسؤول الخادم، ومن يتسلّم المشروع من Novixa.
**الدليل الكامل المصمَّم:** [`docs/manual/index.html`](../manual/index.html) (و`manual-ar.pdf`). هذه الوثيقة هي «الصفحة الواحدة» التي تسبقه.

## 1) ما الذي يُسلَّم
| العنصر | أين |
|---|---|
| الموقع العام (نسخة المراجعة) | https://hadramout-center.novixa.dev — غير مفهرس، بشريط «نسخة معاينة» |
| لوحة التحكم | `/admin` — عربية، بثلاثة أدوار (مدير، محرر، مراجع ترجمة) |
| الشيفرة | GitHub: `Novixa-dev/hadramout-center-platform` (عام) — الفرع `master` هو ما يُنشر |
| النشر | تلقائي عند الدفع إلى `master` عبر GitHub Actions، بنسخة احتياطية قبله وتراجع تلقائي |
| المحتوى | 1,454 عنصراً منقولة من الموقع القديم + 12 صفحة مؤسسية (7 منها من كتاب العقد) |
| التحويلات | كل روابط الموقع القديم (1,454 معرّفاً) تحوَّل بـ301 إلى مكانها الجديد |

## 2) الحسابات (بلا كلمات مرور)
الأدوار والصلاحيات: [ACCESS_AND_ACCOUNTS](ACCESS_AND_ACCOUNTS.md). كلمات المرور الفعلية في ملف محلي مستثنى من git؛ وأسرار النشر (`DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_SSH_KEY`) في GitHub Secrets. **غيّروا كلمة مرور المدير الأول فور التسلّم.**

## 3) المهام الدورية
| المهمة | التكرار | كيف |
|---|---|---|
| مراجعة تقرير الجودة | أسبوعياً | `npm run quality` ← قائمة عمل للمحررين |
| قراءة نتيجة «Live check» | يومياً (آلي) | تبويب Actions؛ يفتح issue عند الفشل |
| اختبار استعادة النسخ الاحتياطية | شهرياً | `deploy/scripts/restore.sh` على نسخة |
| دمج تحديثات Dependabot | أسبوعياً | بعد نجاح فحوصاتها |
| فحص الأداء | أسبوعياً (آلي) | workflow «Lighthouse» |

## 4) قرارات معلّقة عند المالك
نطاق الإطلاق والاستضافة · مزوّد الترجمة ومفتاحه · قاعدة تخزين Cloudflare (كاش ورمز purge) · التحقق بخطوتين للمدراء · نسخ احتياطي خارج الخادم · مزوّد بريد (النشرة واستعادة كلمة المرور) · مرحلة 2 (المنصات الرقمية).

## 5) ما ينتظر مواد المركز
القائمة الكاملة بمالكيها ومعايير القبول في [خطة العمل](../client/03-action-plan-and-tracking.md) (CF-05…CF-24). الأهم قبل الإطلاق: **CF-24 مراجعة المركز لأرقام وأسماء الصفحات المنقولة من الكتاب.**

## 6) قائمة تحقق الإطلاق
- [ ] اعتماد المركز (CF-24) وتسليم المواد الأساسية.
- [ ] نطاق واستضافة جديدان؛ اتباع [دليل الانتقال](../05-deploy/03-move-to-new-host-and-domain.md).
- [ ] `SITE_URL` و`SITE_ENV=production`، وإعادة إنشاء الحاوية.
- [ ] `node scripts/cutover-check.mjs https://النطاق` بلا فشل.
- [ ] Search Console + إرسال الخريطة؛ مراقبة وقت التشغيل.
- [ ] تجربة استعادة نسخة احتياطية على المضيف الجديد.
- [ ] مراجعة يدوية بقارئ شاشة ولوحة مفاتيح.
