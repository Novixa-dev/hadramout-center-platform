# كتالوج الميزات (Feature Catalog)

> العميل فتح الباب لأي ميزة احترافية مناسبة. الأولويات: **P0** أساس لا يُسلَّم دونه · **P1** قيمة عالية ننفذها الآن · **P2** إن اتسع الوقت · **BL** مؤجّل (Backlog).

## أ) الأساسيات (P0)

| الرمز | الميزة | القيمة |
|---|---|---|
| F-01 | ترجمة آلية ar→أي لغة + ذاكرة + قاموس + مراجعة | شرط العميل الأول |
| F-02 | لوحة إدارة عربية (أخبار، مقالات، كتب، مجلات، فعاليات، فيديو، صفحات، وسائط) | العميل لا يعدّل كوداً |
| F-03 | استيراد كامل للموقع القديم + إعادة توجيه 301 | عدم فقد أي محتوى أو رابط |
| F-04 | بحث عربي ذكي (تطبيع الحروف والتشكيل، البادئات) + اقتراحات + مرشحات | الباحث يصل لما يريد |
| F-05 | روابط حقيقية لكل صفحة ولكل لغة + `hreflang` + خرائط موقع | أرشفة وتشارك |
| F-06 | بطاقات مشاركة (OG/Twitter) حقيقية من الخادم لكل عنصر | واتساب/تيليجرام يعرضان الغلاف والعنوان |
| F-07 | واجهة متجاوبة 320→4K، وضع ليلي، RTL/LTR | R1 |
| F-08 | أمان ورؤوس وحماية الإدارة | معيار |
