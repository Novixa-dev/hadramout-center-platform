# سجل القرارات المعمارية (ADR)

| الرمز | القرار | البدائل التي رُفضت | السبب |
|---|---|---|---|
| ADR-01 | تطبيق **SSR + SQLite** بدل موقع ثابت | موقع ثابت (Astro/11ty) · Next.js + Postgres | العميل يحتاج إدخال محتوى وترجمة آلية → خادم لازم؛ SQLite تكفي لحجم المركز وتلغي تعقيد قاعدة بيانات منفصلة |
| ADR-02 | **Node 24 + TypeScript بحذف الأنواع الأصلي** | JS صرف · Next.js | أمان أنواع بلا خطوة بناء؛ `node:sqlite` مدمج |
| ADR-03 | **Fastify 5** | Express · Hono | أداء، مخططات، حقن للاختبار، عمق نظام الإضافات |
| ADR-04 | روابط اللغة بـ**مجلد فرعي** `/{lang}/` | نطاقات فرعية · بارامتر | توصية جوجل؛ صيانة أقل؛ شهادة واحدة |
| ADR-05 | **الترجمة من الخادم** مع ذاكرة ترجمة دائمة | Google Translate widget · ترجمة في المتصفح | قابلية الأرشفة، تحكم بالمصطلحات، خصوصية، كلفة تُدفع مرة واحدة لكل نص |
| ADR-06 | **الترجمة عند الطلب** للّغات غير المسبقة | ترجمة الكل مسبقاً | 912 مقالاً × 90 لغة مكلف وغير ضروري؛ الطلب الفعلي يحدد ما يُترجم |
| ADR-07 | **لا تُطلق الترجمة من GET** | ترجمة عند أول طلب من أي زائر | حماية من الزواحف ونفاد الميزانية |
| ADR-08 | الواجهة **بلا إطار JS** | React/Vue | السرعة على شبكات ضعيفة؛ المحتوى قراءة بالأساس |
| ADR-09 | **ألوان الهوية الرسمية** (أخضر `#2A836E` + ذهبي `#C49952`) | الكحلي+الذهبي السابق | احترام هوية المؤسسة |
| ADR-10 | **Docker + Caddy** للنشر | systemd + nginx يدوي · Vercel | HTTPS تلقائي، قابل للتكرار، يعمل على أي VPS |
| ADR-11 | **لقطة محتوى مضغوطة** تُودَع في المستودع | الاعتماد على الموقع الحي وقت النشر | الموقع القديم سيُوقف؛ نريد بناءً قابلاً للتكرار |
| ADR-12 | **محرر Quill** للإدارة | Tiptap · Markdown | يعمل مباشرة، تسهيلات RTL، تعلّم ضئيل للموظفين |
| ADR-13 | **سياسة عدم التلفيق** فحص آلي | ثقة بالمحررين | أي نوع/حقل مؤسسي بلا مصدر يُرفض في الاستيراد ويُوسَم draft |
| ADR-14 | الفروع + PR + CI قبل الدمج (بدل الدفع المباشر لـmaster) | الدفع المباشر | أمان النشر الآلي: كل دمج في `main` ينشر |
| ADR-15 | الأرقام اللاتينية (0-9) في كل اللغات | هندية-عربية للعربية | اتساق مع الاستشهادات والموقع القديم |
