# نموذج المحتوى وخطة الترحيل

## 1. أنواع المحتوى وحقولها

كل الأنواع في جدول `posts` بحقول مشتركة، وحقول خاصة داخل `fields` (قابل للترجمة) و`data` (غير قابل للترجمة).

| النوع | الحقول المشتركة | `fields` (عربي قابل للترجمة) | `data` |
|---|---|---|---|
| `news` | title, excerpt, body, cover, published_at | `dateline` (المكلا / إعلام المركز) | — |
| `article` | title, excerpt, body, cover?, published_at | `author_line` | `magazine_id` (العدد المنشور فيه)، `category`، `pdf` |
| `book` | title, excerpt (الوصف), body, cover | `author`, `publisher`, `edition` | `year`, `pages`, `isbn`, `pdf`, `order_url` |
| `magazine` | title, body (محتويات العدد), cover | `editor_note` | `issue_number`, `pdf`, `season` |
| `event` | title, body, published_at | `speaker`, `moderator`, `venue`, `time_text` | `event_date`, `end_date`, `link` |
| `forum` | كما `event` | كما `event` | كما `event` + `youtube` |
| `video` | title, body | `guest` | `youtube_id`, `duration` |

**التعقيم:** `body` يُخزَّن HTML معقّماً بقائمة بيضاء: `p, h2–h4, ul, ol, li, blockquote, strong, em, u, sup, sub, a[href], img[src,alt], figure, figcaption, table…, br, hr`. تُزال الأنماط والفئات والسكربتات و`&nbsp;` الزائدة والفقرات الفارغة.

## 2. الكتّاب

`authors(name, name_key)` حيث `name_key` = الاسم بعد تطبيع الحروف وإزالة الألقاب (د./أ.د./أ./الأستاذ/الدكتور/الشيخ/السيد…). يُجمَع المتشابه تحت صفحة واحدة، والاسم المعروض هو الأكثر تكراراً. تُراجَع الحالات الملتبسة يدوياً من لوحة الإدارة (دمج/فصل).

## 3. ربط المقال بالعدد

صفحة المقال القديمة تحوي رابط «هذه المقالة منشورة في ← /magazines/{id}»؛ يُخزَّن في `data.magazine_id`، وتعرض صفحة العدد المقالات المرتبطة.

## 4. الاستيراد (`src/importer`)

```
npm run import:legacy        # يسحب الموقع الحي → content/legacy-snapshot.json.gz
npm run db:seed              # يحمّل اللقطة إلى SQLite (يمكن تكراره بأمان)
npm run import:images        # ينسخ الصور محلياً ويولّد الأحجام (قابل للاستئناف)
```

1. **الاستكشاف:** تمر على صفحات الترقيم لكل قسم حتى الصفحة الفارغة، وتجمع المعرّفات.
2. **السحب:** كل صفحة تفاصيل مرة واحدة (تأخير 250ms، User-Agent معرِّف، إعادة محاولة بتراجع أسي، استئناف من ذاكرة مؤقتة).
3. **الاستخراج:** من كتلة `S:n` المخفية (مع بدائل احتياطية)، يُستخرج: العنوان، التاريخ، الحقول المسمّاة، نص HTML، الصور، روابط PDF/YouTube.
4. **التنظيف:** تعقيم، حذف بيانات Zoom (Meeting ID/Passcode)، تطبيع الأرقام والتواريخ العربية.
5. **التحقق:** يقارن العدد المستخرج بالعدد المعدود لكل قسم، ويطبع تقريراً بالعناصر الناقصة/الفارغة.
6. **اللقطة:** `content/legacy-snapshot.json.gz` (مضغوطة) تُودَع في المستودع كمصدر حقيقة للمحتوى الأولي — **لأن الموقع القديم سيُوقف بعد التحويل**.

## 5. معايير قبول الترحيل

- [ ] عدد كل نوع في القاعدة = العدد المعدود من الموقع الحي (391/912/52/53/40/2/11 ± ما يُوثَّق)
- [ ] صفر `<script>` أو `style=` أو `onclick` في أي `body`
- [ ] كل عنصر له عنوان وتاريخ صالح
- [ ] كل مقال مرتبط بعدده حيث وُجد الرابط، وكل رابط داخلي قديم مُحوَّل
- [ ] 301 تعمل لكل رابط قديم (اختبار آلي على عيّنة وعلى كل المعرّفات)
- [ ] لا بيانات اجتماعات (Zoom) في الأرشيف
- [ ] عيّنة بشرية: 20 عنصراً تُقارَن بصرياً مع الأصل

## 6. المحتوى الجديد (غير مستورد)

| المحتوى | المصدر | الحالة |
|---|---|---|
| صفحة «عن المركز» | وصف المركز الرسمي + بيانات الإدارة الموثّقة (الرئيس: أ.د. عبد الله سعيد الجعيدي، رئيس مجلس الإدارة: أ. محمد سالم بن علي جابر) + المنتدى | منشورة، **تُراجَع من إدارة المركز** |
| الخط الزمني | حقائق تاريخية عامة معروفة | منشورة بوسم «بحاجة مراجعة علمية» |
| الخصوصية/الشروط/الوصولية | صياغة قياسية | منشورة، **تُراجَع قانونياً** |
| أرقام الصفحة الرئيسية | حساب حي من القاعدة | آلي، لا أرقام مكتوبة يدوياً |
