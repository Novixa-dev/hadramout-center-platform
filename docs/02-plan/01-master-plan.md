# الخطة الرئيسية لإعادة البناء (Master Plan)

**المشروع:** المنصة الرقمية لمركز حضرموت للدراسات التاريخية والتوثيق والنشر
**الإصدار المستهدف:** 2.0.0 · **المنفذ:** Novixa · **الحالة:** قيد التنفيذ (راجع `../03-tracking/TRACKER.md`)

## 1. الرؤية

بوابة بحثية ثنائية القلب: **أرشيف رقمي سريع وموثوق** للباحث، و**واجهة عالمية** تُقرأ بأي لغة، ويديرها طاقم المركز في المكلا بالعربية فقط.

## 3. المبادئ الحاكمة

1. **لا تلفيق:** لا بيانات مؤسسية بلا مصدر. ما لا مصدر له يُوسَم `draft` ولا يظهر للعموم. (قاعدة قديمة في المشروع انتُهكت — تُفرض الآن بفحص آلي.)
2. **العربية هي المرجع:** كل الترجمات آلية/مشتقة، وتُعرض بشارة واضحة مع رابط للأصل.
3. **تحسين تدريجي:** الصفحات تعمل بلا JavaScript (قراءة، بحث، تنقل)؛ الجافاسكربت يضيف التحسين فقط.
4. **الأداء كميزة:** ميزانية صارمة للشبكات الضعيفة.
5. **قابلية التسليم:** كل ما يُبنى يمكن للمركز تشغيله وصيانته؛ لا قفل بائع.
6. **القياس قبل الادعاء:** أي رقم في الوثائق مصدره أمر قياس مُسجَّل.

| المرحلة | المخرج | معيار القبول |
|---|---|---|

| **1 — الأساس** | هيكل المشروع، TypeScript، خادم Fastify، قاعدة SQLite وهجرات، قوالب SSR، i18n أساسي، بناء الأصول | `npm test` يمر؛ `/healthz` يعمل |

| **3 — الواجهة العامة** | كل الصفحات + البحث + الاستشهاد + القارئ + SEO | اختبارات تكامل + فحص بصري 6 مقاسات |
| **4 — نظام الترجمة** | مزوّدات + قائمة مهام + قاموس + ظهور اللغات | اختبارات بمزوّد وهمي؛ تدفق كامل ar→en→fr |
| **5 — لوحة الإدارة** | CRUD لكل الأنواع + ترجمات + رفع صور + مستخدمون + إعدادات | اختبار تدفق إنشاء/تعديل/نشر/ترجمة |
| **6 — ميزات احترافية** | PWA، خلاصات RSS، تقويم .ics، محفوظات، تحليلات مجهولة… | حسب الكتالوج |
| **7 — الجودة** | اختبارات وصولية وأداء وأمان، إصلاح النتائج | تقارير في `04-qa/` |
| **8 — النشر والتسليم** | Docker، CI/CD، وثائق VPS، الاختبار البشري، دليل الإدارة | وثائق قابلة للتنفيذ حرفياً |

## 5. تعريف «الإنجاز» (Definition of Done) لكل مهمة

- [ ] الكود مكتوب بأنواع صارمة، يمر `npm run typecheck` و`npm run lint`
- [ ] اختبار آلي واحد على الأقل يغطي المسار الأساسي
- [ ] لا نص عربي في الكود خارج ملفات اللغة (`locales/`) أو المحتوى
- [ ] خصائص منطقية للـCSS (RTL/LTR) — لا `left/right`
- [ ] الوصولية: تركيز مرئي، تسميات، تباين ≥ 4.5:1
- [ ] لا `innerHTML` بنصوص غير معقّمة
- [ ] مُحدَّث في `TRACKER.md` و`CHANGELOG.md`
- [ ] Commit بصيغة Conventional Commits
