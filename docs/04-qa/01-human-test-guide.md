# دليل الاختبار البشري (قبل الاعتماد)

اختبر على: هاتف أندرويد + آيفون + حاسوب، وعلى الأقل متصفحين (Chrome وSafari/Firefox). سجّل كل ملاحظة في الجدول بنهاية الملف.

## أ. الموقع العام
| # | الاختبار | المتوقع |
|---|---|---|
| 1 | افتح الرئيسية بعرض 320px ثم 768 ثم 1280 | لا تمرير أفقي، النصوص واضحة، القائمة تتحول إلى زر ☰ دون 1280 |
| 2 | بدّل الوضع الفاتح/الداكن | الألوان مقروءة، الشعار والبطاقات سليمة، يُحفظ الاختيار |
| 3 | افتح «المقالات» ثم صنّف بالسنة/التصنيف/الترتيب وانتقل بين الصفحات | تعمل الفلاتر والعدّ |
| 4 | افتح مقالة | العنوان، المؤلف، التاريخ، الفهرس، أدوات القراءة (حجم الخط)، الاقتباس (APA/MLA…) |
| 5 | زر المشاركة، الحفظ في «محفوظاتي»، الطباعة | تعمل؛ الطباعة تخفي القوائم |
| 6 | ابحث بكلمة عربية بدون تشكيل أو بألف مختلفة (إ/أ/ا) | نتائج متطابقة؛ الاقتراحات تظهر أثناء الكتابة |
| 7 | اللغات: English ثم Français ثم لغة نادرة (مثل Türkçe) | الواجهة تتغير؛ المحتوى غير المترجم يظهر بالعربية مع شريط «جارٍ إعداد الترجمة» ثم يُحدَّث |
| 8 | افتح رابطاً قديماً مثل `/articles/9597` | يحوّل إلى الصفحة الجديدة |
| 9 | نموذج التواصل والنشرة (بريد غير صالح ثم صالح) | رسائل خطأ/نجاح بالعربية |
| 10 | `/ar/xyz` | صفحة 404 مفيدة |

## ب. لوحة الإدارة `/admin`
| # | الاختبار | المتوقع |
|---|---|---|
| 1 | الدخول بحساب المدير | واجهة عربية RTL |
| 2 | إنشاء مقالة (عنوان + نص + مؤلف + تصنيف) ونشرها | تظهر بالموقع خلال دقيقة وتدخل البحث |
| 3 | افتح الموقع بالإنجليزية بعد النشر | تُترجم تلقائياً وتظهر بعد ثوانٍ |
| 4 | عدّل ترجمة إنجليزية يدوياً ثم عدّل العربية | تبقى ترجمتك اليدوية ولا تُستبدل |
| 5 | حساب «محرر» وحساب «مراجع ترجمة» | المراجع يعدّل اللغات غير العربية فقط |
| 6 | رسائل التواصل والمشتركون | تظهر لمن يملك الصلاحية فقط |

## ج. المحتوى المنقول
اختر **20 عنصراً عشوائياً** من الموقع القديم وقارنها: العنوان، المؤلف، التاريخ، النص، الصور. الثغرات المعروفة (7 صفحات معطوبة في الموقع القديم نفسه) مسجّلة في `docs/01-audit/02-legacy-site-analysis.md`.
**يجب على المركز تأكيد** صفحة «عن المركز» وأسماء القيادة قبل الإطلاق.

## د. الأمان والأداء (للمطوّر)
- `curl -I https://النطاق` ⇒ وجود CSP وHSTS وX-Content-Type-Options.
- Lighthouse للجوال: الأداء ≥ 90، الوصولية ≥ 95، SEO ≥ 95.
- محاولات دخول خاطئة متكررة (5) ⇒ يُقفل الحساب مؤقتاً.
