# التقرير النهائي — منصة مركز حضرموت للدراسات التاريخية والتوثيق والنشر

**التاريخ:** 2026-10-15 · **الإنتاج:** https://hadramout-center.novixa.dev · **المستودع:** Novixa-dev/hadramout-center-platform

## 1. ما هو المشروع
منصة معرفية وأرشيفية رقمية للمركز: العربية هي الأصل، وتُقرأ بأي لغة بالترجمة الآلية، مع أدوات للباحثين (بحث عربي ذكي، استشهاد علمي، فهرسة Google Scholar). حلّت محل موقع قديم ثابت المحتوى.

## 2. المعمارية والتقنيات
| الطبقة | الاختيار | السبب |
|---|---|---|
| الواجهة والخادم | Next.js 16 (App Router، ISR) + React 19 | سرعة وSEO وتوحيد الواجهة والخادم |
| إدارة المحتوى | Payload CMS 3 (لوحة عربية بأدوار) + محرر TipTap | العميل يدير كل شيء دون كود |
| قاعدة البيانات | SQLite (libSQL) + قاعدة ثانية للبحث FTS5 والإحصاءات | بساطة وصفر صيانة؛ نسخة تطبيق واحدة |
| الترجمة | محرك داخلي + مزوّدون (Cloudflare Workers AI المجاني، Anthropic، Google، LibreTranslate) | ذاكرة ترجمة بالتجزئة، قاموس مصطلحات، حماية التعديل اليدوي |
| النشر | Docker + GitHub Actions + nginx(mailcow)/Cloudflare | نشر آلي مع فحص صحة وتراجع |
| الاختبار | node:test (50) + axe + typecheck + ESLint | |

## 3. الميزات
- **المحتوى:** 909 مقالات، 52 كتاباً، 40 عدداً من المجلة، 388 خبراً، 53 فعالية، 11 لقاء منتدى، مرئيات، 274 كاتباً، خط زمني.
- **الباحثون:** بحث عربي (يتجاوز اختلاف الألف والتشكيل والبادئات) + اقتراحات + مرشحات؛ استشهاد APA/MLA/Chicago/Harvard/BibTeX/RIS/CSL-JSON؛ وسوم `citation_*` وJSON-LD؛ RSS؛ تحويلات 301 للروابط القديمة.
- **اللغات:** ≈90 لغة؛ منتقي لغة منسدل ببحث وشارات رموز؛ العربية الافتراضية دائماً؛ شريط «ترجمة آلية» شفاف؛ hreflang للترجمات المكتملة فقط.
- **التجربة:** متجاوب 320px→4K، وضع ليلي، طباعة أكاديمية، أدوات قراءة (حجم الخط)، حفظ/مشاركة.
- **الإدارة:** أدوار (مدير/محرر/مراجع ترجمة)، محرر WYSIWYG، تنقية HTML على الخادم، رسائل التواصل والمشتركون.

## 4. الأمان
CSP وHSTS وnosniff وframe-ancestors none · حدود معدل وhoneypot للنماذج · قفل الحساب بعد 5 محاولات · تنقية كل نص غني عند الحفظ (تحقّقتُ من حجب `script` وonerror وjavascript: وiframe غريب) · أسرار خارج المستودع · SSH بمفتاح وبصمة مضيف مثبّتة.

## 6. التشغيل
- **النشر:** دمج في `master` ← فحص ← بناء صورة ← شحن SSH ← تشغيل ← فحص صحة ← تراجع تلقائي عند الفشل (≈5 دقائق).
- **الخادم:** Contabo VPS مشترك (يحوي mailcow وغيره)؛ حاوية `hadramout-center-app` خلف nginx وCloudflare؛ البيانات في volume `hadramout-center_hc_data`.
- **النسخ الاحتياطي:** يومياً 03:15 إلى `/opt/hadramout-center/backups` (14 نسخة)، وقد تحققتُ من سلامة نسخة (integrity_check ok، 909 مقالة). **ينقص:** نسخ خارج الخادم.
- **المراقبة:** `GET /api/hc/health` (أضفه إلى UptimeRobot).

## 8. المخاطر والقيود المعروفة
1. **الترجمة غير مفعّلة بعد:** تحتاج رمز Cloudflare (انظر `docs/06-handover/translation-guide-ar.md`). لم تُختبر على الإنتاج بعد؛ الاختبار الآلي بمحاكاة فقط.
2. **جودة الترجمة المجانية** تصلح للفهم وتحتاج مراجعة بشرية للنصوص المحورية.
3. **SQLite على خادم واحد:** يكفي مئات آلاف الزيارات شهرياً؛ التوسع الأفقي يتطلب Postgres.
4. **خادم مشترك:** الذاكرة محدودة (≈2.7GB متاحة)؛ حاوية التطبيق محدودة بـ1GB.
5. **«عن المركز» وأسماء القيادة** نصوص مؤقتة بانتظار تأكيد المركز.
6. لم يُجرَّب Docker محلياً (بيئة التطوير بلا Docker)، لكن الإنتاج يعمل ويُنشر آلياً.
