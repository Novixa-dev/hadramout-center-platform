# Security policy

The Hadhramout Center platform (https://hadramout-center.novixa.dev, later https://hadramout.center) is maintained by Novixa.

## Reporting a vulnerability

Please report privately — **do not open a public issue**:

- GitHub: **Security → Report a vulnerability** on this repository (private vulnerability reporting), or
- email **hello@novixa.dev** with the subject `Security: hadramout-center`.

Include the URL or file, the steps to reproduce and the impact you expect. We acknowledge within 3 working days and keep you informed until a fix is deployed. Please give us reasonable time to fix before any disclosure, and do not access other people's data, run denial-of-service or automated scanning at volume against the live site.

## Supported version

Only the `master` branch, which is what is deployed, receives fixes.
