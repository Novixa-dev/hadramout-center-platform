# Quality Assurance

Tiers: (1) unit tests `npm test`; (2) type/lint `npm run check`; (3) production build `npm run build`; (4) integration tests `npm run test:int`; (5) browser verification across viewports; (6) accessibility (axe) and Lighthouse on key pages.
Never report "100%" without a recorded measurement under `docs/04-qa/`.
